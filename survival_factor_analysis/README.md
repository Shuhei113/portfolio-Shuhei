## Assignment Details

### Grade Achieved: **A+** (Outstanding)

### Problem 1: Survival Analysis
**Task:** Analyze customer churn duration using the **Proportional Hazards Model (Cox Model)**.
* Discussed the impact of Direct Mail (DM) on churn rates.
* Evaluated demographic factors affecting customer retention.

### Problem 2: Factor Analysis
**Task:** Comparative analysis of measurement models using **Confirmatory Factor Analysis (CFA)**.
* Compared 1-Factor vs. 2-Factor models using fit indices (GFI, RMSEA, AIC).
* Refined the model by excluding low-loading variables to improve validity.
